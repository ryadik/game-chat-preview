# Game Message Popups

Плагин для RuneLite выводит игровые сообщения OSRS поверх игрового viewport. Текст появляется над сценой даже при открытой вкладке Clan. По умолчанию это красный полужирный текст размером 18 px с тёмной обводкой. Он появляется сразу в верхней части viewport, остаётся непрозрачным 1,6 секунды и затухает за 650 мс.

## Локальный запуск

1. Установите JDK 17. Gradle Wrapper включён в проект и при первом запуске скачает Gradle и зависимости. Проект компилируется в байткод Java 11 и использует RuneLite 1.13.7.
2. Откройте терминал в папке проекта. На macOS, если системная Java новее 17, выберите JDK командой `export JAVA_HOME="$(/usr/libexec/java_home -v 17)"`.
3. Выполните `./gradlew build` для компиляции и тестов, затем `./gradlew run` для запуска RuneLite с плагином. В PowerShell используйте `.\gradlew.bat build` и `.\gradlew.bat run`. Сборка создаёт JAR в `build/libs/`.
4. В клиенте откройте настройки **Game Message Popups**. Для входа с Jagex Account используйте панель авторизации клиента разработчика. [Инструкция RuneLite по входу с Jagex Account](https://github.com/runelite/runelite/wiki/Using-Jagex-Accounts)

## Настройка

- **Position → Preview** показывает постоянный пример вместо игровых сообщений после входа в мир. Удерживайте **Alt** (на macOS **Option**) и перетащите текст левой кнопкой. Если в настройках RuneLite изменён **Overlay drag hotkey**, используйте его. Позицию сохраняет RuneLite.
- **Horizontal position (%)** и **Vertical position (%)** задают положение относительно видимой игровой области. После перетаскивания используется сохранённая позиция. Чтобы вернуться к процентам, удерживайте клавишу перетаскивания и щёлкните правой кнопкой по тексту. Выключите **Preview** после настройки.
- **Appearance** содержит список **Font family**, независимые переключатели **Bold**, **Outline** и **Shadow**, а также размер, цвет и максимальную ширину текста. Для другого установленного шрифта выберите **Custom** и укажите его имя в **Custom font family**. Длинный текст переносится. Если строк больше, чем помещается, конец сообщения сокращается многоточием.
- **Timing** задаёт минимальную задержку, время показа с полной непрозрачностью и длительность затухания в миллисекундах. Ноль в **Fade-out** убирает анимацию.
- **Messages** дополнительно включает фильтруемые игровые сообщения (`SPAM`) и описания **Examine**. По умолчанию показываются `GAMEMESSAGE` и `ENGINE`. Список типов исключает сообщения Clan, Friends, Private и Public.

Одновременно отображаются до трёх сообщений. Остальные ждут своей очереди и получают время показа с момента появления. Очередь хранит до 12 ожидающих сообщений и удаляет самое старое при переполнении. Сообщение, которое ждёт свободного места пять секунд после своей задержки, пропускается. При выходе или смене мира очередь очищается.

## Проверка в игре

Войдите в мир, выберите **Classic Fixed** и включите **Preview**. Перетащите пример к краям viewport и проверьте, что он остаётся в игровой области. Выключите **Preview**, откройте вкладку **Clan** и вызовите игровое сообщение. Для воспроизводимой проверки временно включите **Show examines** и выберите **Examine** на предмете или объекте. Сообщение должно появиться над сценой и затухнуть с заданной скоростью. Чтобы проверить сохранение позиции, перезапустите клиент и снова включите **Preview**.

Структура сборки и запуск клиента основаны на [официальном шаблоне RuneLite](https://github.com/runelite/example-plugin). Метаданные для Plugin Hub находятся в `runelite-plugin.properties`.
